# 📅 Week 2 – Linear Regression

The second week introduces **Machine Learning** using **Linear Regression**.

The project uses the **Iris dataset** to predict **Petal Length** based on **Sepal Length**.

## 📚 Topics Covered

* Loading datasets
* Selecting features and labels
* Train-test splitting
* Linear Regression
* Model training
* Making predictions
* Model evaluation
* Understanding regression metrics

## 🔹 Feature

```text
SepalLengthCm
```

## 🎯 Target

```text
PetalLengthCm
```

## 📊 Model Evaluation

The Linear Regression model is evaluated using:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* R² Score

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
