## 📅 Week 1 – Pandas Basics

The first week focuses on the fundamentals of **Pandas** using the Iris dataset.

* Pandas installation
* Reading CSV files
* DataFrame basics
* `head()`
* `info()`

* Saving cleaned datasets

## 📅 Week 2 – Linear Regression

The second week introduces **Machine Learning** using Linear Regression.

The project uses the Iris dataset to predict **Petal Length** based on **Sepal Length**.

### Topics Covered

* Features and labels
* Train-test split
* Linear Regression
* Model training
* Predictions
* Model evaluation

### Feature

SepalLengthCm

PetalLengthCm
